# PLAN ÉDITORIAL DE LANCEMENT — NOVADECORUSA.COM

Document compagnon du Prompt Maître V1.4. À utiliser avec Claude Code : chaque ligne de ce plan devient une commande d'article (étape 1 du processus, section 6 du prompt maître).

## 0. Logique de construction

Le site a 0 article publié. Pour respecter la structure hub-and-spoke (section 11 du prompt maître), chaque cluster doit être lancé en commençant par son Pillar, puis ses 4 Satellites — le Pillar existe déjà (même en brouillon) quand les Satellites y sont liés, ce qui rend les liens vers lui vivants dès le deuxième article de chaque cluster.

Les 5 catégories narratives (WarmMinimalism, Textures, Palette, RoomEdit, Lighting) forment chacune leur propre cluster Pillar + 4 Satellites. Les 3 catégories restantes (ShopTheLook, DecorGuides, Sanctuary) fonctionnent en articles autonomes, distribués entre les clusters pour rythmer la publication et diversifier le contenu.

**Ordre de lancement des clusters** : WarmMinimalism en premier — c'est la catégorie fondatrice, celle qui pose la philosophie du site et vers laquelle tous les autres clusters pourront renvoyer par la suite.

## 8. Comment utiliser ce plan avec Claude Code

Pour chaque ligne du calendrier, la commande à donner à Claude Code suit ce format :

« On passe à l'article suivant du plan éditorial : [titre], catégorie [X], rôle [Pillar/Satellite] du cluster [nom du cluster]. Présente-moi le plan selon l'étape 1 du prompt maître. »

Claude Code présente le plan détaillé dans le chat (étape 1), attend la validation, puis rédige et intègre en brouillon (étape 2). L'ordre du calendrier garantit que chaque Satellite trouve toujours son Pillar déjà existant (même en brouillon) au moment de sa rédaction, donc un lien interne vivant plutôt qu'un placeholder.
